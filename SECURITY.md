## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly so we can investigate and address it.

- **Reporting:** Submit a private vulnerability report through the GitHub Security tab using the Security Advisories feature.
- **Initial Response:** You can expect an initial response within 3–5 business days.
- **Investigation:** Reported vulnerabilities will be reviewed and investigated.
- **Accepted Reports:** If a vulnerability is confirmed, we will work on a fix and release a security update when appropriate.
- **Declined Reports:** If a report is not considered a security vulnerability, we will provide an explanation when possible.

Please avoid publicly disclosing security vulnerabilities until we've investigated and resolved them.

We appreciate your help in keeping this project secure and protecting its users.

Note: Make sure GitHub Security Advisories is enabled and that the 3–5 business day response commitment is realistic before publishing.
